Live VRROOM BETA

Read-only connection to your VRROOM over IP. Follows the official protocol exactly (no command header over IP, paced commands, strict timeouts). It can never change a setting.

Experimental. This feature only ever sends whitelisted get commands, one at a time, and aborts on repeated timeouts. If the device ever misbehaves, power cycle the VRROOM and use config file export instead. Writing settings (phase 2) will build on this once reads are proven stable.
